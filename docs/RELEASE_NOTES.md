# NerfLens 0.3.1

正式版支持 GTNH 2.9.1 与 ExtraNerf 1.0.1、1.1.0、1.1.1、1.2.0、1.2.1、1.3.0。本次为 0.3.0 的译名修正，显示规则、档案划分与数量不变。

- 修正 1.3.0 档案中残留的旧译名：拉多X聚合物（原 Radox 聚合物）、炉渣（原矿渣）；钛铁矿渣作为另一种材料保持原名。
- 铁浴、QFT、凯芙拉与任务书相关条目现在统一使用游戏内名称：兰波顿超级电容库、量子操纵者、任务书、炉渣、拉多X聚合物、锻铁／铸铁／生铁／过渗碳铁。
- 1.3.0 档案仍为 104 条提示、178 条配方对照；1.2.0（100／176）与 1.2.1（102／177）逐字节保留，1.0.1／1.1.0／1.1.1 不变。
- 其余内容与 0.3.0 相同：QFT 两份 0 数量催化、铁浴部件与分批浇铸、兰波顿超级电容库激光仓认证、任务完成奖励对全队、工业脑腐机低于 1 刻的超频并行。

安装前保存并完全退出客户端，移出旧 NerfLens，只将 `NerfLens-0.3.1.jar` 放进实例 mods 目录。ExtraNerf 已是 1.3.0 时只需替换 NerfLens。

构建和集成验证见 [VALIDATION.md](VALIDATION.md)。
