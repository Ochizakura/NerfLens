# NerfLens 0.3.0

正式版支持 GTNH 2.9.1 与 ExtraNerf 1.0.1、1.1.0、1.1.1、1.2.0、1.2.1、1.3.0。

- 新增独立 1.3.0 档案：104 条提示、178 条配方对照。1.2.0（100／176）与 1.2.1（102／177）继续逐字节保留。
- QFT 塑料路线新增两份 0 数量催化：64 蜂窝路线放入 1 份拉多X聚合物粉，24 蜂窝路线放入 1 份凯芙拉粉，均不消耗。NEI 只在这两条路线显示局部黄框，未改动产物不继承金框。
- 铁浴四金属（锻铁、铸铁、生铁、过渗碳铁）补齐板、杆、齿轮、小齿轮、转子和工具部件，并新增锻铁／过渗碳铁金属方块。悬停这些部件可查看材料来源与身份说明。
- 铁浴浇铸改为按批分步：满批分 10 步、每步最多 1/10 批、至少间隔 5 刻，出口排空后继续；拆掉控制器会丢弃浴槽内容，保存并重载世界仍保留。
- 兰波顿超级电容库的认证等级计入激光能源仓与激光动力仓；任务完成奖励会为当前队伍全部成员标记完成，包括离线成员。
- 工业脑腐机低于 1 刻的超频现在增加并行数，基础并行公式保持 1 + 2 × 电压等级差。
- 新增 3 个已改变英文含义的中文补缺分支；游戏内已有译文、TX Loader、资源包与动态注入继续优先，未匹配的英文不套用旧译文。术语按已安装中文语言文件对齐（兰波顿超级电容库、量子操纵者、任务书、炉渣等）。
- 保留此前太阳能级硅、公共副产物、NBT 变体、NEI 页面复用、Shift 细节和中文优先级修复。

安装前保存并完全退出客户端，移出旧 NerfLens，只将 `NerfLens-0.3.0.jar` 放进实例 mods 目录。ExtraNerf 已是 1.3.0 时只需替换 NerfLens。

构建和集成验证见 [VALIDATION.md](VALIDATION.md)。
