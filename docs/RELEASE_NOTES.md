# NerfLens 0.2.1

适配官方 ExtraNerf 1.2.1，保留对 1.0.1、1.1.0、1.1.1、1.2.0 的自动识别。

- 新增独立 1.2.1 档案：102 条提示、177 条配方对照。旧 1.2.0 档案冻结为 100 条提示、176 条配方对照。
- 生物培养基原液的额外奇异粉投入改为 1 小撮／批次（完整粉末的 1/4）；对照同时说明从 1.2.0 升级时减少 75%。三种培养路线的流体放大不放大这项投入。
- QFT 的 Radox 聚合物／熔融凯芙拉路线增加 64 凯芙拉蜂窝。按真实蜂窝注册名 `gregtech:gt.comb`、metadata 161、材料及四种流体产物匹配。新增投入显示局部黄框，目标塑料显示局部金框。
- 凯芙拉蜂的突变亲本由无尽催化剂蜂改为硅岩蜂；唯一特产为基础概率 7.5% 的凯芙拉蜂窝，移除凯芙拉粒特产。原 LCR 雄蜂投入和 ZPM 复制机要求保留。
- 同步铁浴炉的控制器平台输入位置、最多一个烟囱测量仓、50 个同种线圈、五层浇铸预览、流体锁定、外壳禁止刷怪与分辨率自适应界面说明。
- 同步无线能源覆盖板的能源仓认证限制，保留只读认证状态显示。
- 新增 8 个中文补缺键，为 8 个已改变英文含义的键增加独立译文。实际 1.2.1 中核对 95 条缺译文本、6 条保持原文的数学／数量格式和原生中文优先级。
- 保留此前太阳能级硅、公共副产物、NBT 变体、NEI 页面复用、Shift 细节和中文优先级修复。

安装前保存并完全退出客户端，移出旧 NerfLens，只将 `NerfLens-0.2.1.jar` 放进实例 mods 目录。ExtraNerf 已是 1.2.1 时只需替换 NerfLens。

构建和集成验证见 [VALIDATION.md](VALIDATION.md)。本更新包的 GitHub 同步由单独的发布步骤完成。
