# NerfLens 0.2.0

正式版支持 GTNH 2.9.0 和 ExtraNerf 1.0.1、1.1.0、1.1.1、1.2.0。

- ExtraNerf 1.2.0 使用独立档案：100 条提示、176 条配方对照，覆盖电力铁浴、钢与合金路线、凯芙拉蜂、终端、玻璃、回收及奖励变化。
- 修正太阳能级硅等原生矿辞标识，避免提示与金框漏匹配；公共副产物、特定加工路线和不同 NBT 变体不再错误继承全局标记。
- 默认提示显示原版与现版；保留真实配方数量，支持容器分支和隐藏数量图标的模式。
- 补齐中文缺译；已有模组与资源包译文继续优先。保留 NEI 对照与只读认证状态。

本正式版沿用已核验的 rc6 功能与数据，更新发布版本及说明。

安装时关闭客户端，移出旧 NerfLens，只将 `NerfLens-0.2.0.jar` 放进实例 mods 目录。构建和集成验证见 [VALIDATION.md](VALIDATION.md)。
